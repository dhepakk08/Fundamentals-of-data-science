FODS LAB PRACTICE — QUESTIONS 01–20

Each numbered folder contains one standalone Python program, its required upload file, and a short Colab run note. Upload only the dataset in the matching folder, then paste program.py into a Colab code cell and run it. pandas, NumPy, Matplotlib, SciPy and scikit-learn are available in standard Colab runtimes.

Data notes:
- Labs 6, 14 and 15 use clearly labeled illustrative synthetic data because no matching grocery, purchase-date or post-like dataset was included.
- Lab 1 uses four students and the four requested subjects from the supplied marks file; missing marks in that small sample are filled with the column median.
- Lab 8 reports the latest month present in the supplied historical order data; it is not necessarily the current month.
- Lab 9 uses furnishing status as the available location-like grouping because the supplied property data has no location column.
- Lab 12 uses the first year of the supplied monthly weather series; the source does not identify a city.
- Lab 18 uses a reproducible sample of 18 adults from the supplied body-fat dataset.
- Lab 11's next-month number is a simple linear trend estimate, not a validated forecasting model.
- Lab 20 compares binary conversions as proportions using a two-sided two-proportion z test.
